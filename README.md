# ClockIt
ClockIt is a full-stack web application for managing shift assignments, attendance, and wage tracking for daily wage workers. It enables supervisors to schedule shifts and track payouts, while workers can clock in/out, view schedules, and monitor earnings through an interactive, user-friendly interface.
